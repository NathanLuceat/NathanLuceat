### 01 — [Webblioteca](https://github.com/NathanLuceat/webblioteca)

**Library Management System**

`PHP` `Laravel` `MySQL` `Docker` `Laravel Sanctum` `PHPUnit`

A web application for managing physical book loans and study room reservations.

**Technical highlights:**
- Relational database modeling using MySQL.
- Authentication and role-based access control.
- REST API with token-based authentication using Laravel Sanctum.
- Business rules for book availability, loans and room reservations.
- Administrative dashboard and user management.
- Automated tests using PHPUnit.
- Containerized development environment with Laravel Sail.

This project explores backend architecture, data consistency and real-world business rules.

[Explore repository](https://github.com/NathanLuceat/webblioteca)
